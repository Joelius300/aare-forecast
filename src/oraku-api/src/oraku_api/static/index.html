Das Aare Orakel ist ein Vorhersagesystem für die Wassertemperatur der Aare. Bisher kann das Orakel nur die Temperatur in Bern für die nächsten 1–2 Tage vorhersagen. Dabei erreicht es meistens eine Genauigkeit von 0.1 – 0.5 °C daneben. Da es aber noch viel lernen muss und von potenziell ungenauen Wettervorhersagen abhängig ist, sind auch Abweichungen von 1 °C oder mehr möglich. Eine technische Analyse zur erwarteten Genauigkeit kann hier gefunden werden. In kommenden Jahren werden zusätzliche Daten gesammelt und neue Versionen trainiert, um die Genauigkeit zu verbessern.

Am Kern des Orakels steht ein eigenes trainiertes Machine Learning Modell. Alle 15 Minuten werden die Wasser- und Lufttemperaturdaten der letzten 24 Stunden sowie die Lufttemperaturprognose für die kommenden Tage zu einer Wassertemperaturprognose verrechnet. Diese werden dann via API für aare.guru zugänglich gemacht. Weitere Details zur Umsetzung sowie der komplette Code für die Datenanalyse, das Modelltraining, die umliegenden Services und mehr sind öffentlich einsichtlich unter Joelius300/aare-forecast.

In zukünftigen Versionen sollen die Vorhersagen genauer werden und weiter in die Zukunft gehen. Mehr Städte und ein Unsicherheitsmass sind ebenfalls angedacht. Wie alles beim Aare Guru ist das Orakel ein Hobbyprojekt und es kommt wanns kommt.
